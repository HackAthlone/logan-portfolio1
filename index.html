Project 1: Blackjack Game (GUI)

A graphical Blackjack game where the player competes against the dealer. This project demonstrates game logic, basic GUI design and user interaction.

How it works:

  • Player is dealt two random cards, dealer receives two (one hidden)
  • Player can hit for more cards or stand to lock in their score
  • Game calculates card values dynamically (Aces = 1 or 11)
  • Dealer auto-plays following Blackjack rules (must hit below 17)
  • Win/lose conditions shown in GUI with updated card graphics

Tech: Java / Python GUI (depending on your version)

Project 2: Arduino Nuclear Meltdown Simulator

An educational hardware project that simulates a nuclear reactor meltdown scenario using Arduino, Raspberry Pi and cloud logging. It models sensor readings (e.g. temperature or “radiation” levels), triggers alarms, and visualises data online.

How it works:

  • Arduino reads “reactor” sensor values in real time
  • Raspberry Pi collects and processes the incoming serial data
  • Critical thresholds trigger sirens, LEDs & warning indicators
  • Live data is pushed to ThingSpeak for IoT graphing
  • Dashboard displays temperature & alert status in the cloud

Tech: Arduino, Raspberry Pi, ThingSpeak, Python, embedded C

Watch demo video (MP4)

Project 3: Garage Booking Service

A web-based garage booking system that lets customers book service slots online and stores all bookings in a database. The project combines a Java back-end with an HTML front-end and persistent data storage.

How it works:

  • Customer selects date, time and service type via an HTML form
  • Java back-end receives and validates the booking request
  • Booking details are saved into a relational database
  • Garage staff can view scheduled bookings for each day
  • Designed to reduce double-bookings and manual admin work

Tech: Java, HTML/CSS, databases (SQL), basic web architecture
